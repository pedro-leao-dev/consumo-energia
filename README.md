\## 📌 Sobre o Projeto



A \*\*Calculadora de Consumo Elétrico Inteligente\*\* é uma aplicação em Python desenvolvida para estimar o consumo de energia mensal (em kWh) e o custo estimado em Reais (R$) de eletrodomésticos a partir da sua potência e uso diário.



\## 🧮 Fórmula Utilizada



$$\\text{Consumo Mensal (kWh)} = \\frac{\\text{Potência (W)} \\times \\text{Horas/Dia} \\times 30}{1000}$$
